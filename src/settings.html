General

The helper starts in the tray when you sign in, ready to use.

Shortcuts

Start and stop recording
A key with modifiers, like Ctrl+Alt+Space, or two modifiers alone, like Ctrl+Alt, which act when you tap and release them.
Show the terminal list
Like Alt+Tab: hold Ctrl, press Tab to move down (with Shift, up), let go to pick. Windows then gives this shortcut only to the helper, so a browser or an editor no longer gets it.
