General

The helper starts in the tray when you sign in, ready to use.
Claude Code
Connect it for the cards when Claude finishes or needs you, the "Selected" line in its status bar and your shell prompts, and screenshots it opens without asking. Restart Claude Code sessions afterwards.
Updates
New versions download on their own; a card offers to restart into them.
Log and problem reports
The log records what the helper did and any errors. It also holds the text you dictated, so look it over before you share it.

Shortcuts

Start and stop recording
A key with modifiers, like Ctrl+Alt+Space, or two modifiers alone, like Ctrl+Alt, which act when you tap and release them.
Show the terminal list
Like Alt+Tab: hold Ctrl, press Tab to move down (with Shift, up), let go to pick. Windows then gives this shortcut only to the helper, so a browser or an editor no longer gets it.
